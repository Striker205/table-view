# TableView

TableView is a desktop application built in Java Swing for tracking 1-year and 3-year product warranties.

[Application visual](./TableView.png)

## About the Project

This application was created to help manage product warranties in a simple and practical way. It focuses on tracking warranty periods and notifying the user when a warranty has expired.

When a product is out of warranty, the application highlights the related record with a color indicator and also shows a Windows notification. A yellow highlight is used for expired 1-year warranties, while a red highlight is used for expired 3-year warranties.

## Features

- Track 1-year and 3-year product warranties
- Highlight expired warranty records with color indicators
- Show Windows pop-up notifications for expired warranties
- Import and export Excel files
- Add new records
- Edit existing records
- Delete records
- Save changes
- Extend warranty periods for selected records

## Tech Stack

- Java
- Java Swing
- Excel import/export
- Windows OS notifications

## Purpose

The main purpose of the application is to make warranty tracking easier and more organized. Instead of checking warranty dates manually, the user can manage all records in one place and get a clear visual warning when a warranty has expired.
